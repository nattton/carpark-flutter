# 🚗 Carpark Flutter

A **production-ready Flutter project** for car park management with full **cross-platform support**.

This repository contains a complete Flutter application focused on clean architecture, scalable structure, and real-world deployment readiness.

---

## ✨ Overview

**Carpark Flutter** is a cross-platform application built with **Flutter & Dart**, designed to provide a solid foundation for car park management systems.

The project focuses on:

- Clean and maintainable Flutter architecture
- Production-grade project structure
- Cross-platform deployment from a single codebase
- Scalable UI and business logic

---

## 🖥️ Platform Support

This project supports building and running on:

- ✅ Windows
- ✅ macOS
- ✅ Web
- ✅ Android
- ✅ iOS

All platforms are built from the same Flutter codebase.
